Ground floor

The Charge of the Car

cdd-configdrift-AlertOnSchemaViolation validates a configuration file against a JSON schema and gives the alert when the configuration violates the schema, working through the jsonschema library.

Desk notice

The alert as documented takes the form of a printed validation error and a failing exit, with no other channel named anywhere in the README. The wider word in the opening line is narrowed here to what the verified results make plain.

Taking the Car Up

The install block as the README writes it, clone from the ShadowGuard-AI account, step into the directory, pip install from requirements.txt:

git clone https://github.com/ShadowGuard-AI/cdd-configdrift-alertonschemaviolation
cd cdd-configdrift-alertonschemaviolation
pip install -r requirements.txt

Then the working line, with its format and log level options bracketed before the two passengers every ride carries:

python3 main.py [-f json|yaml] [-l LEVEL] CONFIG_FILE SCHEMA_FILE
